\chapter{Artefactos de análisis}

Para entender las necesidades de los usuarios y definir la interacción con la plataforma se emplean Historias de Usuario y Casos de Uso. Las Historias de Usuario se centran en los deseos de los usuarios finales y sus expectativas, mientras que los Casos de Uso describen las funcionalidades de la aplicación junto con sus flujos de acción.

\section{Workflows}

Los flujos de trabajo definen la secuencia de pasos que sigue el usuario para completar una tarea relacionada con un Caso de Uso. Detallan las rutas principales de navegación, las respuestas del sistema y el manejo de excepciones.

\begin{longtable}{p{3cm}p{7.1cm}p{5.3cm}}
\hline\textbf{Caso}&\textbf{Flujo principal}&\textbf{Alternativas / excepciones}\\\hline
CU01&1. Seleccionar ``Registrarse. 2. Mostrar formulario. 3. Completar datos. 4. Validar credenciales. 5. Almacenar credenciales. 6. Invocar CU07. 7. Activar perfil e iniciar sesión.&Credenciales duplicadas: mostrar error. Encuesta incompleta: bloquear avance (RN02).\\
CU02&1. Abrir la aplicación. 2. Detectar sesión. 3. Invocar el motor de recomendación con encuesta e historial TF-IDF. 4. Calcular similitud coseno. 5. Mostrar recomendaciones.&Sin sesión: invocar CU08. Sin encuesta: mostrar cafés mejor valorados e invitar a completarla.\\
CU03&1. Introducir texto o filtros. 2. Confirmar. 3. Validar parámetros. 4. Consultar por descripción, notas u origen. 5. Mostrar coincidencias.&Sin coincidencias: notificarlo y sugerir relajar filtros.\\
CU04&1. Abrir carrito. 2. Verificar autenticación. 3. Solicitar pago y dirección. 4. Confirmar importe. 5. Enviar cobro. 6. Autorizar. 7. Guardar orden e historial. 8. Mostrar comprobante.&Usuario anónimo: detener y redirigir a login. Pago rechazado: mantener carrito y permitir reintento.\\
CU05&1. Acceder al panel. 2. Elegir alta, modificación o baja. 3. Completar datos y fotos. 4. Guardar. 5. Validar. 6. Procesar y vectorizar descripción y actualizar catálogo.&Campos vacíos o formatos erróneos: resaltar el campo y detener el guardado.\\
CU06&1. Acceder a login. 2. Solicitar credenciales. 3. Introducirlas. 4. Comprobar BD. 5. Generar JWT e iniciar sesión.&Campos incompletos o credenciales inválidas: mostrar error y solicitar reintento.\\
CU07&1. Presentar encuesta. 2. Responder y guardar. 3. Registrar respuestas y generar vector inicial.&Campos incompletos: bloquear el avance (RN02).\\
CU08&1. Acceder a portada sin sesión. 2. Detectar anonimato. 3. Recuperar los 10 más vendidos o mejor valorados. 4. Mostrar carrusel. 5. Invitar a registrarse.&Error de catálogo: notificar y usar datos en caché.\\
CU09&1. Abrir ``Mi perfil. 2. Recuperar respuestas. 3. Modificar y guardar. 4. Validar. 5. Recalcular vector.&Datos erróneos: resaltar campos y detener actualización.\\
CU10&1. Añadir producto. 2. Actualizar contador. 3. Abrir carrito. 4. Ajustar o eliminar artículos. 5. Recalcular totales. 6. Proceder al pago.&Sin stock: avisar y desactivar botón. Carrito vacío: deshabilitar compra.\\
CU11&1. Pulsar ``Cerrar sesión. 2. Revocar JWT. 3. Redirigir al inicio anónimo.&Error de red: eliminar credenciales locales y forzar salida.\\
CU12&1. Acceder a administración. 2. Calcular ventas y usuarios activos. 3. Mostrar indicadores.&Error de métricas: notificar y habilitar reintento.\\
CU13&1. Listar cuentas. 2. Seleccionar objetivo. 3. Pulsar ``Suspender. 4. Introducir motivo. 5. Confirmar. 6. Cambiar estado e inhabilitar acceso.&Cancelación: conservar el estado activo.\\
CU14&1. Abrir solicitudes. 2. Revisar datos. 3. Aprobar o rechazar. 4. Actualizar BD. 5. Notificar por correo.&Documentación incompleta: marcar pendiente de corrección y añadir observaciones.\\
\hline
\end{longtable}
